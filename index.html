📜 RÈGLES DU JEU

🎯 Objectif

Formez des mots avec TOUTES les lettres tirées pour marquer un maximum de points en M manches (2 par défaut).

📝 Déroulement d'une manche

  • 1. Vous tirez N lettres (12 par défaut)
  • 2. Cliquez sur les lettres dans l'ordre pour former un mot (min. 2 lettres)
  • 3. Vous pouvez relancer jusqu'à 2 fois certaines lettres
  • 4. Marquez vos mots puis validez votre tour
  • 5. L'ordinateur joue ensuite avec son propre tirage

🏆 Système de points

  • Score = somme des carrés des longueurs
  • p.ex. les mots RAT, REDONNER rapportent 3×3 + 8×8 = 73 points
  • Score = 0 point si un mot n'est pas valable ou si toutes les lettres ne sont pas utilisées

🎮 Contrôles

  • Vérifier : Teste si le mot est valide sans le marquer
  • Marquer : Valide le mot sélectionné (lettres deviennent vertes)
  • Relancer : Change les lettres sélectionnées (max 2 fois)
  • Abandonner mot : Désélectionne les lettres du mot en cours
  • Clic sur mot vert : Retire ce mot marqué et libère ses lettres
  • Meilleure solution : Affiche la meilleure combinaison possible
  • 100 plus longs mots : Affiche les 100 mots les plus longs formables
  • Tirage manuel : Saisissez les lettres du tirage vous-même (n'importe quelle longueur)
  • Valider tour : Termine votre tour et lance l'ordi
